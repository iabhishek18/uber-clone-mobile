# Uber Clone - Ride Sharing Mobile App

Full-featured ride-sharing app with React Native, real-time GPS tracking, and fare calculation.

## Features
- 🗺️ Real-time GPS tracking with Google Maps
- 🚗 Multiple ride types (Economy, Premium, XL)
- 📍 Live driver location updates via Socket.io
- 💰 Dynamic fare calculation (Haversine distance)
- ⭐ Rating system for drivers & riders
- 📱 Cross-platform (iOS + Android)

## Tech Stack
- **Mobile**: React Native, Expo, React Navigation, react-native-maps
- **Backend**: Node.js, Express, Socket.io, MongoDB
- **Maps**: Google Maps Platform

## Getting Started
```bash
cd server && npm install && npm run dev
cd mobile && npm install && expo start
```
